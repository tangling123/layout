## 2. 待验证清单（实现到对应里程碑时逐条关闭）

| 编号 | 主题 | 待确认内容 | 计划验证方式 |
|---|---|---|---|
| DIF-001 | GDS `AREF` 步距 | `P1-P0` 除以 `cols` 还是 `cols-1`；不同工具的历史差异 | gdstk 生成已知尺寸的 3×2 阵列 + KLayout 截图 |
| DIF-002 | GDS `STRANS` 顺序 | mirror → rotate → mag 的实际矩阵顺序 | 4 类用例（纯旋转 / 镜像+旋转 / 缩放 / 组合） |
| DIF-003 | GDS `MAG` 为负 / 0 | 负放大（等效镜像）与 0（退化）如何处理 | 构造文件 + KLayout 行为对比 |
| DIF-004 | `PATHTYPE=4` 延伸 | `BGNEXTN/ENDEXTN` 是绝对长度还是相对宽度 | 与规范文本 + KLayout 对比 |
| DIF-005 | 文本锚点 | `PRESENTATION` 对齐位的实际渲染位置 | 固定相机截图对比 |
| DIF-006 | OASIS flip 与 angle | flip 在旋转之前还是之后 | 规范 + KLayout |
| DIF-007 | OASIS `REPETITION` | 各类型的步距方向（是否随 cell 变换旋转） | 每类型一个用例，逐实例断言 |
| DIF-008 | OASIS modal 重置点 | `CELL` 边界是否重置全部 modal 值 | 构造跨 cell 的模态依赖文件 |
| DIF-009 | 图层渲染顺序 | 默认按 `(layer, datatype)` 还是文件出现顺序 | 与 KLayout 默认层序对比 |
| DIF-010 | 半透明叠加 | 是否做透明混合排序 | 视觉对比（记录我们的选择即可） |
| DIF-011 | 编辑态拖动基准 | 拖动时吸附到最近顶点/边，还是"按下点"作基准 | 同图同操作对照 KLayout |
| DIF-012 | 撤销粒度 | 多选批量移动是一步还是每元素一步 | 操作 3 个图形后看 undo 次数 |
| DIF-013 | 打散（Flatten）默认层数 | 默认只打散一层还是递归到底 | 演示层次样例对比 |
| DIF-014 | 保存时的 cell 顺序与属性 | GDS 磁盘序、`PROPATTR` 顺序是否与 KLayout 一致 | 双方保存后二进制/dump 对比 |
| DIF-015 | 保存时 >8191 点多边形切分 | 切分方式（沿最长边 / 凸分解）与结果顶点 | 构造 9000 点多边形，KLayout 读回对比 |
| DIF-016 | 原地保存后的文件时间戳/大小 | 原子写会不会让 `mtime` 变化导致 KLayout 的小地图标/缓存失效 | 保存后用 KLayout 打开，观察是否提示重新加载 |
| DIF-017 | `.lyp` 写回的字段顺序 | 我们保留原顺序，KLayout 是否会重排 | 同一 `.lyp` 双方各存一次，diff XML |
| DIF-018 | 图层属性是否进撤销栈 | KLayout 改层色/显隐是否可撤销 | 改层色后连按 `Cmd+Z` 观察是否回退 |

### 3.1 已知会存在的差异（已接受）

| 编号 | 主题 | 现象 | 原因 | 结论 | 影响 | 测试 |
|---|---|---|---|---|---|---|
| DIF-101 | 不支持脚本化 DRC / LVS / PCell | KLayout 能做规则驱动检查与参数化单元，本工具不能 | 范围控制（README §6） | 本项目不做；只做结果查看 | 用户需在 KLayout 侧生成静态版图 | `10 §15` 记录 |
| DIF-102 | 图像底层参考（Image view） | KLayout 可叠加参考图并做对准 | 未排期 | 暂不支持 | 影响衬底/显微图对照场景 | — |
| DIF-103 | 3D / 剖面视图 | KLayout 有 | 不做 | 长期不做 | 无 | — |
| DIF-104 | 不交付 Windows | KLayout 有 Windows 版 | 仅 macOS + Linux | 不提供 Windows 构建 | Windows 用户需用 KLayout 或自行移植 | 交付清单 |
| DIF-105 | 原地保存默认留 `.bak` | KLayout 备份策略可配 | 我们默认每次保存前留一份 `<file>.bak` | 更保守（可关） | 磁盘多一份文件 | `test_save_atomicity` |
| DIF-106 | 崩溃残留临时文件恢复 | KLayout 无此提示 | 我们扫描 `<target>.tmp-*` 并提示恢复 | 额外安全网 | 启动可能多一次对话框 | `test_tmp_recovery` |
| DIF-107 | 图层属性改动不进撤销栈 | 待实测（DIF-018） | 视图状态，仅置 `lypDirty` | 待实测确认 | 误改层色只能手动改回 | `test_lyp_roundtrip` |
