**原则**

- 一个类一个 `.h/.cpp`，文件名 = 类名 snake_case；目录 = 模块。
- **界面文案只有英文**：不建 `resources/translations/`，不调用 `qt_add_translations()`。
- `core` / `editing` / `command` / `io/gds` 保持「无 Qt 依赖」，便于 `eda_dump` 命令行与 CI 纯 C++ 测试。
- 不把 UI 逻辑混进 `render`；不把渲染细节混进 `scene`。

## 2. CMake 目标与依赖

```
eda_core    (STATIC)      : 无外部依赖（纯 C++20）
eda_io      (STATIC)      : core + ZLIB
eda_scene   (STATIC)      : core + io + Qt6::Core + Qt6::Concurrent
eda_editing (STATIC)      : core + io + Clipper2（**不依赖 Qt**）
eda_command (STATIC)      : core + editing（**不依赖 Qt**，见 11）
eda_render  (STATIC)      : core + scene + Qt6::Gui + Qt6::OpenGL + Qt6::OpenGLWidgets
eda_ui      (STATIC)      : render + editing + command + Qt6::Widgets + Qt6::Svg
eda_app     (EXECUTABLE)  : ui + app + command + plugin → 目标名 `eda`
eda_dump    (EXECUTABLE)  : core + io + editing + command（无 GUI，CI 用；`--write` 做往返测试）
tests       (CTest)       : Qt6::Test + 各静态库
```

- 依赖用「**PUBLIC 接口依赖 / PRIVATE 实现依赖**」表达；头文件不泄漏实现细节。
- `target_compile_features(cxx_std_20)`、`-Wall -Wextra -Wpedantic`；Debug 开
  `-fsanitize=address,undefined`（由 preset 控制）。
- Qt 用 `qt_standard_project_setup()` + `qt_add_executable()`；macOS 设
  `MACOSX_BUNDLE TRUE`；资源 `qt_add_resources()`。**不做翻译**（无 `qt_add_translations()`）。
- 第三方：`find_package(ZLIB REQUIRED)`；Qt 组件
  `Core Gui Widgets OpenGL OpenGLWidgets Concurrent Svg Test`。
- **Clipper2（V2，E3 起必需）**：`add_subdirectory(third_party/clipper2)`，只被 `eda_editing` 的
  `boolean_ops` 使用；`EDA_WITH_CLIPPER2=OFF` 时相关代码不编译（接口仍可链接空实现，
  保证 V1 构建不需要它）。

**CMakePresets 关键项**

| preset | 生成器 | 选项 |
|---|---|---|
| `mac-debug` | Ninja | `Debug` + sanitizer + `QT_HOST_PATH` 指向 6.7 |
| `mac-release` | Ninja | `RelWithDebInfo`（先不开 LTO，保编译速度） |
| `linux-debug` / `linux-release` | Ninja + gcc 12+ | 同样的选项；CI 用 Ubuntu 22.04 验证 glibc 2.35 基线 |

## 3. 编码规范

| 项目 | 约定 |
|---|---|
| 命名空间 | `eda::core`、`eda::io`、`eda::scene`、`eda::editing`、`eda::render`、`eda::ui`、`eda::app` |
| 类型名 | `PascalCase`（`SceneGraph`、`GlRenderer`） |
| 函数/变量 | `camelCase`（`hitTest`、`pxPerMicron`） |
| 成员变量 | `m_` 前缀（`m_layout`） |
| 常量 | `k` 前缀（`kMaxDepth`） |
| 头文件 | `#pragma once`；尽量前向声明，减少 include |
| 错误 | 不跨模块抛异常；用 `Result<T>`；`assert` 只用于内部不变量 |
| 资源 | RAII；禁止裸 `new/delete`；Qt 对象用父子关系，GL 对象用 RAII 包装 |
| 格式化 | `.clang-format`：LLVM 基础、4 空格、列宽 100、`PointerAlignment: Left` |
| 静态检查 | `.clang-tidy`：`bugprone-*`、`modernize-*`、`performance-*`（逐步开启） |
| 注释 | 解释「为什么」与「规范依据」（如 "P39：modal 在 CELL 边界重置"），不复述代码 |
| 提交 | 一个提交一件事；信息写「动词 + 模块 + 目的/现象」 |

## 4. 测试策略

### 4.1 分层

| 层 | 工具 | 覆盖重点 |
|---|---|---|
| 单元测试 | Qt Test（无 GUI 模块用 `QTEST_APPLESS_MAIN`） | 单位换算、real64、varint、变换合成、AREF 布局、网格索引、LOD 决策、SlotMap、事务 |
| 解析/写入集成 | Qt Test + 样例文件 | GDS/OASIS 端到端：图元数、层、bbox、单位、警告数；读→写→读一致 |
| 编辑语义 | Qt Test（纯 core/editing） | 提交/回滚/嵌套、撤销全还原、层次不变量、增量场景、吸附 |
| 渲染黄金图 | Qt Test + `QImage` 比较 | 固定相机 + 小样例，容忍 ≤ 2% 像素差异；只在 macOS 上跑 |
| 性能基准 | `eda_dump --bench` + 脚本 | 打开耗时、内存峰值、帧时间分布、编辑提交耗时 |
| 模糊测试（可选） | libFuzzer + 两个 Reader | 坏输入不崩溃、不 OOM |

### 4.2 必测清单（对应 04 的验证策略）

1. GDS real64：0、±1、0.001、1e-9、极端值。
2. UNITS 两种常见配置 → `micronsPerDbu` 正确。
3. SREF：无变换 / 旋转 30° / 镜像+旋转 90° / 缩放 0.5（坐标与 KLayout 一致）。
4. AREF：3×2、旋转后、镜像后，逐实例断言原点。
5. 层次：A→B→C、循环引用、缺失 cell、空 cell。
6. OASIS：varint 边界、modal 重置、delta 还原、CBLOCK、REPETITION 各类型、表格引用。
7. 坏文件：截断、长度非法、超长字符串、坐标越界。
8. 拾取：重叠图元、细线、多层 zOrder。
9. 相机：`zoomAt` 定点性（缩放后该像素下的世界点不变）、`zoomFit` 边界、极限缩放。
10. 图层：全隐/全显、单层高亮、改色后重绘。
11. **SlotMap**：删除后再插入不复用旧 generation；遍历跳过空洞；句柄比较。
12. **事务**：提交/回滚/嵌套/空事务；失败路径模型不变；中断时不泄漏。
13. **撤销全还原**：随机 100 步编辑 → 逐步 undo → `eda_dump` 与初始输出逐字节一致。
14. **层次不变量**：插入/删除实例后 parents 双向一致；环路实例被拒绝（`CycleDetected`）。
15. **增量场景**：改一个 cell 后仅该 cell 的 `CellGeometry` 指针变化，父 bbox 正确上溯。
16. **写入往返**：GDS/OASIS 读→写→读，dump 一致；8191 点切分；属性保留。
17. **吸附**：顶点/边/实例原点/网格优先级；重合与极近点的稳定性（同输入同输出）。
18. **保存原子性**：模拟写入失败（磁盘满/权限）→ 原文件完好、临时文件清理。
19. **`.lyp` 往返**：读入工艺厂样例（含未知元素）→ 改一个颜色 → 写出 → 再读，未知元素仍在、
    其余层属性不变；无 `.lyp` 时保存**不凭空创建**。
20. **原地覆盖冲突**：保存前外部改动文件（改 mtime/内容）→ 必须弹冲突对话框，
    选 Cancel 后原文件与内存状态都不变。
21. **临时文件恢复**：手工留下 `<target>.tmp-*` → 打开文件时提示恢复，且不误删正式文件。
22. **命令总线**：未知 ID / 无文档 / 只读 / 编辑模式关闭 / 保存中 / 重入排队 → 均被拒绝且模型不变。
23. **命令撤销**：每个 undoable 命令执行 → undo → `eda_dump` 与初始一致；redo 后再一致（表驱动生成）。
24. **命令文本往返**：`parse → format → parse` 幂等；`edit.batch` 中途失败整批回滚；
    命令日志重放产生与直接执行相同的 dump。

### 4.3 运行方式

```
cmake --preset mac-debug          # Linux: cmake --preset linux-debug
cmake --build --preset mac-debug -j
ctest --preset mac-debug --output-on-failure
ctest -R gds --output-on-failure                      # 只跑 GDS 相关
./build/mac-debug/eda_dump --bench samples/big.gds    # 无界面基准
```

CI：macOS(arm64) + Ubuntu 22.04（x86_64）；ASAN 任务单开；黄金图只在 macOS 跑
（字体与抗锯齿差异使跨平台逐像素比较不可靠）。**不设 Windows 任务**（不交付）。

## 5. 调试与诊断

| 需求 | 方法 |
|---|---|
| 看解析过程 | `QT_LOGGING_RULES="eda.io.*=true"`；或 `eda_dump --verbose file.gds` |
| 只看某类日志 | `QT_LOGGING_RULES="eda.render.debug=true;eda.io.gds.debug=false"` |
| 崩溃定位 | Debug 开 ASAN；Release 生成 `.dSYM`（macOS）；Linux 用 `-g` + `objcopy --only-keep-debug` 分离符号 |
| 性能热点 | `xctrace record --template "Time Profiler"`（macOS）；`perf record`（Linux） |
| GL 问题 | Debug 构建开 `QSurfaceFormat::DebugContext` + `QOpenGLDebugLogger` |
| 文件对比 | `eda_dump --format json file.gds` 输出稳定 JSON，两版本 diff |
| 渲染差异 | `--screenshot out.png --camera x,y,scale` 固定视角截图与基线比对 |

**建议的内建诊断开关（设置项，默认关闭）**：显示可见图元数/draw call/上传字节/帧耗时；
显示 cell 包围盒、实例原点、拾取网格；强制软件渲染；禁用 instancing。

`--version` 与「关于」共用。日志与崩溃报告必须带应用版本 + Qt 版本。

## 7. 第一天就能做的「骨架里程碑」（详见 07）

1. 顶层 `CMakeLists.txt` + presets 能配置成功；`eda` 打开空白主窗口。
2. `eda_dump` 能读一个 10 行的 GDS 并打印记录序列（证明 `StreamReader` 正确）。
3. `test_gds_real` 通过（real64 解码正确）。
4. 空场景 + 网格 + 相机交互（`LayoutView` 不依赖解析也能跑）。
5. `test_slotmap` + `test_transaction` 通过（可变模型的地基，V1 就写、不暴露 UI）。
